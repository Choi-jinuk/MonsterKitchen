> 최종 수정: 2026-04-17
> 목적: 게임 설계 결정의 근거가 되는 레퍼런스 데이터 및 인사이트 정리

## 1. 핵심 레퍼런스 게임 심층 분석

### 1.1 Dave the Diver

**GDC 2024 발표 내용 기반 분석**

핵심 루프 구조:
- 하루를 오전 탐험 / 오후 탐험 / 저녁 식당 3구간으로 분리
- "Hunt" 루프 (몬스터/물고기 사냥) + "Explore" 루프 (세계 탐험) 병행
- 두 루프가 같은 공간에서 동시에 작동 → 플레이어가 자연스럽게 두 목표를 추구

**반복성 극복 전략 (우리 게임 직접 적용 가능)**
- 핵심 루프(잠수→식당)를 유지하면서 새 메커니즘을 레이어로 추가
- VIP 손님 등장 → 특수 재료 요구 → 새 파밍 동기 생성 (루프 확장)
- 농장, 씨호스 레이싱 등 서브 콘텐츠가 코어 루프를 방해하지 않고 옵션으로 붙음
- **적용**: 자동 소탕, 포획 미니게임, 요리 대회 등이 같은 방식으로 작동해야 함

**연출 철학 (GDC 발표)**
- "Blending Humor and Gameplay" — 유머와 게임플레이를 분리하지 않고 통합
- 작은 성취(첫 요리, 첫 VIP)에 풀 연출 투자 → "이 정도까지 할 줄 몰랐다"는 반응
- 픽셀아트 + 고해상도 배경 레이어 혼합 → 저예산으로 고감성 구현

### 1.2 Hades

**영구 진행 시스템 (Permanent Progression)**
- 죽음 = 실패가 아닌 진행 수단. 죽어도 자원 획득, 대화, 스토리 해금
- 런 중 획득 자원 → 런 사이 영구 강화에 투자
- 4가지 자원이 각각 다른 용도 → 플레이어가 항상 "다음에 뭘 할지" 있음
- **적용**: 던전 실패 시도 재료 일부 보존, 경험치는 항상 획득 → "시간 낭비" 느낌 제거

**서사와 게임플레이 통합**
- 죽을 때마다 새 대화 → 반복 플레이를 서사 진행으로 전환
- 플레이어가 강해질수록 이야기도 깊어짐
- **적용**: 던전 재도전 시 미아/그롬/아리사의 코멘터리 변화 → 재도전이 스토리 소비

**난이도 자기조절 (Pact of Punishment)**
- 클리어 후 더 어렵게 만들 수 있는 도전 시스템
- 하드 플레이어에게 콘텐츠 수명 무한 제공
- **적용**: Phase 1 클리어 후 "강화 던전" 모드 — 동일 지역 강화 버전 + 희귀 재료 드롭

### 1.3 Stardew Valley / Animal Crossing

**"악마의 게임" 심리학**
- 20분 단위 인게임 하루 → 자연스러운 "한 번 더" 단위 생성
- 세이브 포인트 = 하루 마감 → 그 전에 멈추기 어려운 구조
- 플로우 상태: 자기 부여 목표 + 즉각 피드백 → 몰입 유지
- 내재적 동기 (외부 보상이 아닌 행동 자체의 만족)가 핵심
- **적용**: 인게임 하루 = 던전 구역 클리어 → 식당 영업 → 마감. 플레이어가 자연스럽게 "오늘 하루 마감하고 싶다"는 욕구 생성

**압박 없는 성장**
- Animal Crossing: 강제 퀘스트 없음. 해야 할 일은 있지만 기한 없음
- 진행이 느려도 매일 새로운 것이 있음 → 복귀 동기
- **적용**: 스태미나 없음 결정의 근거. 플레이어가 원하는 속도로 진행

---

### 1.4 Genshin Impact

**Engagement First, Monetization Second**
- 무과금으로 수백 시간 플레이 가능한 콘텐츠 설계
- 처음엔 과금의 존재조차 인식 못하고 즐김 → 애착 형성 후 지갑 열기
- **적용**: Phase 1 무과금 완주 원칙의 성공 사례. BM 노출은 Phase 2 이후

**Pity 시스템 (가챠 신뢰성)**
- N회 뽑기 보장 → "언젠간 나온다"는 믿음 유지
- 두 단계 통화 (실제 돈 → 젬 → 뽑기) → 소비 심리적 거리감
- **적용**: Phase 2 가챠 설계 시 천장 시스템 필수

**속성 조합 시스템**
- 원소 반응(불+물=증발 등) → 파티 구성 다양화 동기
- 같은 캐릭터도 파티 조합에 따라 플레이가 달라짐
- **적용**: 우리 게임의 속성×막타 시스템과 동일 구조. 파티 3명 속성 조합이 재료 파밍 전략

### 1.5 Overcooked / Cook Serve Delicious

**초반 직접 조작 → 후반 시스템화의 중요성**
- Overcooked: 모든 걸 직접 해야 하는 카오스 → 재미의 원천
- CSD3: 빠른 마이크로 매니지먼트 → 숙달의 쾌감
- **적용**: 식당 직접 운영 초반이 재미있어야 직원 위임 후 "해방감"이 의미있음
- 초반 식당이 충분히 바쁘고 정신없어야 함 → 손님 밀도, AI 속도 중요

**파이프라인 흐름 설계**
- 재료 준비 → 조리 → 서빙 → 결제 → 설거지 각 단계가 독립적 병목
- 어디서 막히는지 플레이어가 직관적으로 파악 가능해야 함
- **적용**: 주방(요리 슬롯) → 홀(서빙 경로) → 계산대 각 단계별 업그레이드 구조

## 2. 모바일 게임 시장 데이터 (2025)

### 2.1 리텐션 실제 수치

| 기준 | 평균 | 상위 타이틀 |
|---|---|---|
| Day 1 리텐션 | 28% | 40% |
| Day 7 리텐션 | 13% | 15% |
| Day 30 리텐션 | 6% | 6.5% |

> 이탈의 80~90%가 첫 날 발생.
> **Day 1 리텐션이 모든 지표의 출발점** — 첫 5분 온보딩 설계가 가장 중요한 이유.

### 2.2 세션 패턴

- 평균 세션 길이: 캐주얼 4분 / 미드코어 5~6분
- 하루 평균 세션 수: 3~5회
- 총 플레이 시간: 세션당 짧지만 선택한 게임에 집중

> **인사이트**: 세션이 짧은 게 문제가 아님. 우리 게임처럼 "오래 하고 싶은" 게임은
> 세션이 길어도 괜찮음. 단, 짧은 세션도 의미있게 끝날 수 있어야 함 (인벤토리 파밍 → 귀환).

### 2.3 한국 모바일 시장 특성

| 지표 | 수치 |
|---|---|
| RPG 시장 점유율 | 52% (글로벌 평균 20.8%) |
| 아이들 RPG 성장 | 2020년 2% → 2024년 16% |
| 전략 게임 성장 | YoY +69% |
| RPG 총 매출 | $2.1 billion (2024년 10개월) |

> **인사이트**:
> - 한국 유저는 RPG 친화적 → 캐릭터 성장, 파티 구성이 핵심 동기
> - 아이들 RPG 급성장 = "시간 효율적 게임" 수요 증가 → 자동 소탕 기능의 중요성
> - P2W 구조(리니지 계열)가 여전히 수익 상위권 → Phase 2 설계 방향 유효

## 3. 스킬 트리 설계 기준

**실증 데이터**
- 잘못 설계된 스킬 트리: 유의미하게 인식되는 스킬 **17%**
- 잘 설계된 스킬 트리 (AC: Origins): **76%**

**몬스터 키친 스킬 트리 적용 원칙**

| 원칙 | 내용 | 적용 |
|---|---|---|
| 선택이 개성을 만든다 | 어떤 스킬을 올리느냐가 캐릭터 정체성 | 최종 분기 선택 = 캐릭터 빌드 방향 결정 |
| 완성 불가 설계 | 모든 노드를 다 찍을 수 없어야 함 | 포인트 총량 < 전체 노드 수 |
| 스탯+능력 혼합 | 숫자만 올리는 노드는 재미없음 | 1~2단계: 수치 / 3단계+: 질적 변화 |
| 15~40 노드 | 미드코어 게임 적정 규모 | 스킬당 7~10 노드 × 3개 = 21~30 노드 |
| Path of Exile 참고 | 분기점에서 전략적 선택 | 최종 분기 3선택지 구조 |

## 4. BM 설계 기준 (2025 트렌드)

### 4.1 플레이어 친화적 BM 원칙

```
좋은 BM: "더 편하게 즐기고 싶어서 산다"
나쁜 BM: "막혀서 어쩔 수 없이 산다"
```

**2025 성공 패턴**
- 하이브리드 모네타이제이션: IAP + 광고 + 구독 조합
- 코스메틱 마이크로트랜잭션: 가장 플레이어 친화적 + 수익성 높음
- 보상형 광고 (opt-in): 강제 광고 대비 리텐션 손실 없음
- 구독 모델: 2025년 기준 유연한 티어 + AI 최적화 리워드로 진화

**절대 피해야 할 것 (리텐션 파괴)**
- 핵심 진행을 페이월로 막기 (Day 1~3 이내)
- 강제 인터스티셜 광고 (게임 중 갑자기 전면 광고)
- P2W를 Phase 1 유저에게 노출

**몬스터 키친 BM 적용**

| 단계 | 전략 | 근거 |
|---|---|---|
| Phase 1 | 코스메틱 + 편의 + 구독 | 리텐션 최우선, 가챠 미노출 |
| Phase 2 진입 후 | 가챠 + 배틀패스 + VIP | 애착 형성 완료 유저 대상 |
| 광고 | 보상형 opt-in만 | 강제 광고 = 리텐션 파괴 |

## 5. 게임 주스(Juice) 설계 원칙

**전투 피드백 필수 요소**

| 요소 | 효과 | 주의사항 |
|---|---|---|
| 히트 스톱 | 타격감, 공격 무게감 강조 | 과도하면 답답함 |
| 화면 흔들림 | 임팩트 강조, 박력 전달 | 진폭/주기 세밀 조정 필요 |
| 파티클 이펙트 | 시각적 만족감, 속성 구분 | 성능 최적화 필수 |
| 사운드 피드백 | 타격음, 속성별 SFX | 시각과 동기화 |
| 히트박스 점멸 | 피격 인식, 무적 시간 표시 | 명확한 피드백 |

> **핵심 원칙**: Juice는 게임플레이를 보완하는 것. 약한 게임플레이를 숨기는 용도로 사용 금지.
> 먼저 게임플레이가 재미있어야 하고, 그 위에 Juice를 얹는다.

**속성별 SFX/VFX 차별화 (드롭 연계)**
- 냉기 막타: 얼음 결정음 + 파란 파편 파티클 → 재료가 냉동 상태로 드롭하는 시각적 연결
- 불꽃 막타: 화염음 + 붉은 연기 → 재료가 구워진 채로 드롭
- 이 연결이 자연스러울수록 "전투-요리 연계 판타지"가 강해짐

## 6. 하이브리드 캐주얼/미드코어 설계 원칙

**2025년 가장 빠르게 성장하는 카테고리 ($4.2B 시장)**

**성공 공식**
```
Hook (간단하고 즉각적인 코어 루프)
    +
Meta (업그레이드, 수집, 빌드 시스템)
    =
Hybrid Casual
```

**몬스터 키친 포지셔닝**
- Hook: 던전 입장 → 몬스터 처치 → 재료 드롭 (즉각적)
- Meta: 요리 레시피 수집, 스킬 트리, 식당 업그레이드, 스토리
- 분류: Hybrid Casual → Midcore 방향으로 성장하는 구조

**핵심 경고 (업계 데이터)**
- 코어 루프가 재미없으면 메타 레이어가 아무리 풍성해도 실패
- 메타 레이어가 코어를 압도해도 실패 (코어에 집중할 여유 없음)
- **몬스터 키친 리스크**: 던전 전투 "game feel"이 충분히 재미있어야 모든 것이 작동

## 7. 온보딩 설계 데이터

**GDC + 업계 데이터 종합**

| 기준 | 데이터 |
|---|---|
| 첫 날 이탈 | 80~90% |
| 상위 타이틀 Day 1 리텐션 | 40% |
| 온보딩 최적 방식 | 행동 중 학습 (읽기 최소화) |
| 인지 부하 관리 | 첫 화면에 정보 최소화 |

**Easy to learn, Hard to Master 원칙**
- Match게임, Tabletop게임이 리텐션 상위권인 이유
- 첫 30초에 핵심 행동 1가지만 요구
- 이후 시스템은 플레이 중 자연스럽게 등장

**몬스터 키친 적용 (3.4 섹션과 연계)**
- 첫 30초: 공격 버튼만
- 첫 5분: 루프 1회전 완주
- 5분~30분: 시스템 하나씩 소개
- Day 1 이후: 플레이어가 스스로 탐험

## 8. 게임 루프 & 서사 통합 원칙

**Loops and Arcs 구조 (Lostgarden)**
- Loop: 반복 가능한 게임플레이 (던전 탐험, 식당 영업)
- Arc: 일회성 서사 진행 (스토리 이벤트, NPC 관계 변화)
- 최고의 게임은 Loop와 Arc가 서로를 강화함

```
Loop (재미) → Arc (동기) → Loop (더 강한 재미) → Arc (더 깊은 동기)
```

**몬스터 키친 구조**
- Loop: 던전 → 요리 → 식당 영업 (매일 반복)
- Arc: 에이직의 정체, NPC 관계 변화, 공허 오염 진행 (서사)
- 연결고리: 더 깊은 던전 클리어 = 더 진행되는 스토리 = 더 강한 Loop 동기

## 9. 경쟁사 포지셔닝

| 게임 | 우리와 유사한 점 | 우리가 차별화하는 점 |
|---|---|---|
| Dave the Diver | 탐험+식당 사이클, 연출 철학, 점진적 확장 | 탑뷰 액션 전투, 3인 파티, 속성×재료 시스템 |
| Hades | 탑뷰 액션, 서사 통합, 영구 진행 | 식당 경영, 요리 시스템, 모바일 타깃 |
| Genshin Impact | 속성 조합, 파티 구성, 가챠 Phase 2 | 요리 중심 루프, 식당 경영, 배경 세계관 |
| Stardew Valley | "악마의 게임" 루프, 압박 없는 진행 | 직접 조작 전투, 액션 요소, 판타지 배경 |
