# 던전 맵 확장 — 허브 + 3갈래 깊이 진행형 설계

> 작성: 2026-06-11
> 상태: 승인됨 (사용자 확인 완료)
> 선행 스펙: `2026-06-03-dungeon-rework-design.md` (단일 오픈맵 리워크)

---

## 1. 목표

현재 20×16 단일 구역 던전을 **수작업 대형 맵 (약 60×48, 허브 + 3갈래)** 으로 확장한다.
데이브 더 다이버의 초반 맵처럼 **유저 역량(스탯·장비 업그레이드)에 따라 도달 가능한
깊이가 자연스럽게 결정**되는 구조를 만든다.

- **소프트 게이트 (주)**: 깊은 구역일수록 강한 몬스터. 사망 = 가방 전체 소실(기존 패널티).
- **하드 게이트 (1곳)**: 심층 보스 구역 입구를 파괴 가능한 게이트로 차단.
  도구 업그레이드 레벨이 기준 미달이면 데미지가 들어가지 않는다.

## 2. 비범위 (YAGNI)

- 절차 생성 / 복수 던전 / 맵 정의 SO — 도입하지 않음
- 신규 몬스터 — 기존 MON_001~005 재배치만
- 타일맵 아트 — 미페인트 유지 (플레이스홀더 배경 스케일 확대)
- 산소/시간 제한 류 추가 메커니즘 — 없음

## 3. 맵 레이아웃

전체 월드 바운드: **(-30, -24) ~ (30, 24)** — `m_WorldBounds = (-30, -24, 60, 48)`

```
                ┌───────────────┐
                │   심층 안쪽    │   MON_005 보스 ×1 (리스폰 60s)
                │   (보스 구역)  │   희귀 광석 노드 ×2 (RNO_004)
                ├──■ 게이트 ■──┤   ← DungeonGate (도구 Lv2+)
                │   심층 바깥    │   MON_003 ×2 + MON_004 ×2
                └──────┬───────┘
   ┌──────────┐  ┌────┴─────┐  ┌──────────┐
   │ 숲 갈래   │──│   허브    │──│ 암석 갈래 │
   │ (서쪽)   │  │  (남쪽)   │  │ (동쪽)    │
   └──────────┘  └──────────┘  └──────────┘
```

| 구역 | 위치(대략) | 몬스터 | 자원 노드 | 난이도 |
|---|---|---|---|---|
| 허브 | 중앙 하단 (0,-16) 주변 | 없음 (안전) | 없음 | — |
| 숲 갈래 | 서쪽 (-22,-8) 주변 | MON_001 ×4 | 나무(7002) ×4 | 약 |
| 암석 갈래 | 동쪽 (+22,-8) 주변 | MON_002 ×3 + MON_003 ×1 | 바위(7001) ×2 + 광석(7003) ×2 | 중 |
| 심층 바깥 | 북쪽 (0,+8) 주변 | MON_003 ×2 + MON_004 ×2 | 광석(7003) ×1 | 강 |
| 심층 안쪽 | 북쪽 끝 (0,+18) 주변 | MON_005 ×1 (보스) | 희귀 광석(7004) ×2 | 최강 |

- 허브에 `PlayerSpawnPoint` + `DungeonExit` 배치 (입구 = 출구).
- 구역 간 통로는 벽 콜라이더(BoxCollider2D)로 형성. 통로 폭 4~6 유닛.
- 좌표는 구현 시 ±2 유닛 조정 허용.

## 4. 신규 컴포넌트

### 4-1. DungeonGate (`Assets/Scripts/Dungeon/DungeonGate.cs`)

심층 안쪽 입구를 막는 파괴 가능 장애물. ResourceNode 패턴 차용.

- **차단**: 비트리거 BoxCollider2D — NavGrid 베이크 차단 레이어에 배치해 이동·내비 모두 차단.
- **파괴 조건**: `PlayerUpgradeData.ToolDamageLevel >= m_RequiredToolLevel` (기본 2).
  - 미달 시: 데미지 0, `GameHUD.ShowNotification("단단한 바위다 — 더 강한 도구가 필요하다 (도구 공격력 Lv2)")`.
  - 충족 시: `TakeGateDamage(dmg)` → 내구도 차감 (기본 MaxHp 100).
- **파괴 시**: 콜라이더·스프라이트 비활성 + NavGrid 재베이크(또는 장애물 해제). 세션 내 유지.
- **재입장 시 복원**: 씬 리로드로 자연 복원 (상태 저장 없음 — 세션 한정).
- **공격 연동**: ResourceNode 레이어 공유. `PlayerController.TryHarvestNode()` 에
  `DungeonGate` 분기 추가 (인터페이스 신설 없이 GetComponent 분기 — 대상 2종뿐).
- **로직 분리**: 레벨 판정·내구도 계산은 순수 메서드로 분리 → EditMode 테스트 대상.

### 4-2. DungeonZoneTrigger (`Assets/Scripts/Dungeon/DungeonZoneTrigger.cs`)

구역 진입 피드백. 구역당 1개, 트리거 BoxCollider2D.

- 플레이어 진입 시:
  - `GameHUD.ShowNotification(m_ZoneName + m_DangerHint)` — 예: `"심층부 — 위험!"`.
  - `Global Light 2D` intensity 를 `m_LightIntensity` 로 보간 (0.5s).
- 구역별 intensity: 허브/숲 1.0, 암석 0.9, 심층 바깥 0.75, 심층 안쪽 0.6.
- 같은 구역 재진입 시 토스트 생략 (마지막 구역 캐시).
- Inspector 참조: `Light2D` 직접 연결 (FindObject 금지 — 프로젝트 규칙).

## 6. 씬 변경 (DungeonScene)

1. **벽 콜라이더**: RoomBoundaries 재구성 — 외곽 4벽 확장 + 내부 구역 분리벽/통로.
2. **스폰 존**: 2개 → 4개 (숲/암석/심층바깥/보스). 각 존에 SpawnPoint 자식 2~4개 배치.
3. **자원 노드**: 4개 → 11개 (배치표 §3 참조). RNO_004 는 신규 스프라이트 없음 — 기존 광석 플레이스홀더 색 변형.
4. **DungeonGate**: 심층 바깥↔안쪽 통로에 1개.
5. **DungeonZoneTrigger**: 5개 (허브 포함).
6. **DungeonMapController**: `m_WorldBounds = (-30,-24,60,48)`, `m_SpawnZones` 4개 재연결.
7. **Background**: 스케일 확대 (60×48 커버).
8. **NavGrid**: 범위 확장 (Inspector 설정) — Bake 가 새 영역 커버 확인.
9. **카메라 컨파이너**: 새 바운드 반영.
10. **PlayerSpawnPoint / DungeonExit**: 허브로 이동.

## 7. 테스트

- **EditMode**: DungeonGate 순수 로직 — 레벨 미달 데미지 0 / 충족 시 차감 / 내구도 0 → 파괴 플래그.
- **PlayMode**: 기존 스모크 패턴 연장 — DungeonScene 로드 → DungeonMapController 초기화 완료
  + SpawnZones 4개 Init 확인.
- **수동**: 갈래별 몬스터·노드 등장 / 게이트 차단·미달 토스트·파괴 / 구역 토스트·조명 변화 /
  미니맵 마커 4개 / 사망 시 허브 복귀 흐름.

| 리스크 | 대응 |
