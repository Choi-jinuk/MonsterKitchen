# Game Design Document — 몬스터 키친 (가제)

> 최종 수정: 2026-04-17
> 상태: 기획 확정 (v1.2)

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 던전 액션 어드벤처 + 레스토랑 타이쿤 + RPG |
| 플랫폼 | Mobile (iOS/Android) · PC (Windows/Mac) · Web |
| 엔진 | Unity 6 (6000.4.2f1) + URP 2D |
| 시점 | 탑뷰 2D (던전 + 식당 공통) |
| 타깃 등급 | 전체이용가 (12세 이상 목표) |
| 타깃 유저 | 스토리 몰입형 솔로 유저 (초기) · 장기 하드코어 유저 (후기) |

### 한 줄 설명 (초기 노출용)

> "던전에서 잡은 몬스터로 요리하는 판타지 레스토랑 — 탐험하고, 요리하고, 키워라."

> ⚠️ 내부 설계 메모: 경쟁·P2W·길드·랭킹 관련 워딩은 Day 30 이전 유저에게 절대 노출 금지.
> 스토어 페이지, 온보딩, 튜토리얼, Phase 1 전 UI에서 해당 요소 언급 없음.

### 컨셉 & 세계관

던전밥(Delicious in Dungeon) 세계관에서 영감을 받은 게임. 플레이어는 던전 깊은 곳에 위치한 식당의 주인이자 모험가다. 던전의 몬스터들은 그 자체가 최고의 식재료다 — 슬라임은 쫄깃한 젤리, 드래곤은 최고급 스테이크, 해골 기사는 진한 육수의 재료.

레스토랑에 찾아오는 모험가 손님들을 만족시키기 위해 직접 던전에 뛰어들어 식재료를 수확하고, 주방으로 돌아와 요리를 만들어 식당을 운영한다.

## 2. 레퍼런스 분석

### 2.1 던전밥 (Dungeon Meshi)
- **핵심 차용 요소**
  - 몬스터 = 식재료라는 역발상 소재
  - 몬스터 부위별 식재료 분리 (슬라임 핵 → 젤리, 드래곤 날개 → 훈제 요리 등)
  - 던전 생태계 개념 — 몬스터마다 서식지, 특성, 조리법이 다름
  - 요리를 통한 HP 회복 및 버프 메커니즘

### 2.2 용사식당 (Bistro Heroes)
- **핵심 차용 요소**
  - 영웅 파견 → 재료 수급 → 요리 → 판매 → 강화의 순환 루프
  - 클리어한 스테이지 자동 탐험(소탕) 기능
  - 지역별 고유 식재료 및 영웅 영입 시스템
  - 식당 좌석/인테리어 업그레이드
- **개선점**
  - 직접 조작 전투 추가 (용사식당은 반자동) → 쿠키런 방식으로 보완
  - 요리 과정 미니게임 추가로 참여도 향상

### 2.3 쿠키런: 모험의 탑
- **핵심 차용 요소**
  - 직접 조작 액션 (이동·공격·스킬·궁극기) — 시점은 탑뷰로 적용
  - 속성 시스템 (불/물/바람/땅/마법 등) — 몬스터 약점 공략
  - 캐릭터별 고유 스킬 및 역할 분담 (딜러/탱커/서포터)
  - 최대 4인 협동 레이드 모드
  - 던전 목표 다양화 (시간 제한, 섬멸, 방어전 등)
- **개선점**
  - 전투 결과가 식재료 수급량에 직결 (쿠키런은 전투 자체가 목적)
  - 몬스터 포획/부위 공략으로 요리에 영향

### 2.4 데이브 더 다이버 (Dave the Diver)
- **참고 영역**: 게임 확장성 · 장르 설계 · 게임 사이클 · **전체 연출 전략**

**장르 설계 — 경계 없는 장르 혼합**
- 데이브 더 다이버는 RPG + 어드벤처 + 경영 시뮬 + 리듬 게임 + 퍼즐이 자연스럽게 결합된 장르 혼합의 성공 사례
- 각 장르 요소가 억지스럽지 않고 하나의 루프 안에서 녹아들어 있음
- **우리 게임의 적용**: 탑뷰 던전 액션 + 레스토랑 경영 + RPG 성장 + 스토리 어드벤처가 한 게임처럼 느껴지도록 설계

**게임 사이클 — 낮/밤 이중 루프**
- 데이브의 핵심 사이클: **낮 = 바다 탐험(재료 수집)** / **밤 = 초밥집 운영(판매)**
- 두 활동이 서로를 강화: 탐험 잘할수록 식당 메뉴 풍성 → 식당 수익으로 탐험 장비 강화
- **우리 게임의 적용**: **던전 탐험 사이클** / **식당 영업 사이클** 구조 채택
  - 스태미나 제한 없음 — 플레이어가 원하는 만큼 탐험
  - 던전 구역 클리어 → 자연스럽게 식당 영업 페이즈로 전환
  - 식당 마감 후 캐릭터 강화 → 다음 날 더 깊은 던전

**확장성 설계 — 점진적 레이어 쌓기**
- 데이브 더 다이버는 핵심 루프(잠수→초밥집)에서 시작해 농장, 직원 고용, 장비 제작, 협동조합 등을 **한 번에 오픈하지 않고** 스토리 진행에 따라 하나씩 해금
- 각 새 시스템은 기존 루프에 자연스럽게 붙음 — 플레이어가 압도되지 않음
- **우리 게임의 적용**:
  - 초기: 기본 던전 + 3종 메뉴 식당만 존재
  - 진행하며 해금: 레시피 연구, 직원 고용, 자동 소탕, 레이드, 특수 손님 이벤트
  - 새 던전 지역 = 새 재료 = 새 메뉴 라인 → 확장이 루프를 풍성하게 만드는 구조

**연출 철학 — 데이브 더 다이버의 핵심**
- **짧고 임팩트 있는 컷씬**: 새 요리 완성·새 장비 제작·퀘스트 클리어 등 **일상적이고 사소한 순간마다** 짧은 컷씬 재생 (5~10초)
- **과장된 애니 스타일 연출**: 음식 완성 장면을 드라마틱하게 연출 — 빛 터짐, 슬로우모션, 캐릭터 리액션. 진지함과 유머 사이의 균형
- **픽셀아트 캐릭터 + 배경의 레이어 혼합**: 캐릭터는 픽셀아트, 배경은 별도 디테일 레이어 → 감성적 깊이
- **작은 것도 이벤트로**: 신 메뉴 등록, 첫 손님 방문, 재료 발견 등 모든 "처음" 순간에 연출 부여
- **NPC 리액션으로 세계 살리기**: 손님이 음식 먹는 표정, 직원이 바쁘게 뛰는 모습 — 배경도 살아있게

## 3. 핵심 게임 루프 (Core Loop)

### 3.1 하루 사이클 (게임 내 이벤트 기준 — 실시간 아님)

```
━━━━━━━━━━━━━━━━ 하루 ━━━━━━━━━━━━━━━━

  [오전 — 던전 탐험 Phase]
      던전 입장 (제한 없음 — 스태미나 시스템 없음)
          ↓
      몬스터 사냥 → 막타 속성에 따른 식재료 획득
          ↓
      던전 클리어 → 레시피/장비/골드 보상
          ↓
      귀환 → 인벤토리 정리, 요리 준비
          (인벤토리가 가득 차면 자연스럽게 귀환 유도)

  [오후 — 식당 영업 Phase]
      오늘 획득한 재료로 메뉴 구성
          ↓
      식당 오픈 → 손님 응대 → 주문/서빙/결제
          ↓
      영업 마감 → 골드/명성 정산

  [저녁 — 성장 Phase]
      캐릭터 강화 (장비, 스킬 업그레이드)
          ↓
      식당 업그레이드 (주방, 좌석, 인테리어)
          ↓
      새 레시피 연구 / NPC 이벤트 확인

━━━━━━━━━━━━━━━━ 다음 날 ━━━━━━━━━━━━━━━━
더 깊은 던전, 더 희귀한 몬스터, 더 풍성한 메뉴
```

### 3.2 매크로 루프 (장기 — 데이브 더 다이버 확장성 구조 적용)

핵심 원칙: **새 시스템은 한 번에 오픈하지 않고, 스토리 진행에 따라 하나씩 레이어로 추가**

> 일수는 하루 1~2시간 플레이 기준 콘텐츠 볼륨 추정치. 강제 시간 잠금 아님.
> 모든 해금 조건은 스토리 이벤트/던전 클리어 기준.

```
초반 (약 1~7일차 분량)
  기본 던전 1구역 + 식당 메뉴 5종
      ↓
중반 (약 8~20일차 분량)
  던전 2~3구역 해금 + 레시피 연구 시스템 오픈
  직원 고용 가능 + 특수 손님 이벤트 등장
      ↓
후반 (약 21일차~ 분량)
  자동 소탕 가능 + 레이드 던전 오픈
  VIP/비밀 손님 + 전설 레시피 라인
      ↓
엔드게임
  무한 던전 + 시즌 이벤트 + 콜라보
```

### 3.3 마이크로 루프 (단기 세션 — 5~15분)
- 던전 입장 → 몬스터 처치 → 재료 확인 → 메뉴 세팅 → 영업 → 결과 확인
- **어느 Phase에서 시작해도 즉시 즐길 수 있는 구조** (던전만 하거나, 식당만 운영해도 진행 가능)
- 인벤토리가 가득 차는 시점 = 자연스러운 세션 종료 포인트 → 짧은 세션도 완결감 있게 마무리
- 모바일 평균 세션 4~6분 기준, 던전 한 구역 파밍은 이 범위 안에 설계 (DESIGN_REFERENCES 섹션 2.2)

### 3.4 첫 세션 온보딩 — "5분 안에 판타지를 체험시켜라"

> **설계 원칙**: 시스템을 설명하기 전에 감정을 먼저 건드린다.
> 플레이어가 "이 게임 재밌겠다"는 감각을 느끼는 순간이 5분 안에 반드시 있어야 한다.
> 데이브 더 다이버처럼 — 규칙을 알기 전에 이미 손이 가고 있는 상태.

**설계 방향성과의 관계**
- 게임의 깊이와 시스템 복잡성은 **건드리지 않는다** — 튜토리얼에서 단순화하지 않음
- 대신 **진입 경로를 짧게** 만든다: 핵심 판타지("몬스터를 잡아 요리한다")를 5분 안에 직접 체험
- 이후 모든 시스템은 기존 설계대로 **스토리 진행에 따라 하나씩 레이어로 추가**

---

**첫 세션 플로우 (목표: 설치 후 5분 안에 루프 1회전 완주)**

```
[0:00~0:30] — "눈 뜨면 던전"
  UI 설명 없이 바로 에버그린 숲 입장
  미아의 "따라와요!" 한 마디가 전부
      ↓
  첫 슬라임 등장 → 공격 버튼만 강조 (하이라이트)
  처치 → 슬라임 젤 드롭 팝업: "슬라임 젤을 얻었다. 뭔가 만들 수 있을 것 같다..."

[0:30~2:00] — "재료가 생긴다"
  슬라임 2~3마리 추가 (자연스럽게 조작을 익힘, 죽지 않음)
  던전 출구로 미아가 손짓 → 별도 설명 없이 주방으로 이동

[2:00~4:00] — "요리가 완성된다"
  주방 도착 → 레시피 책 자동 오픈: "슬라임 젤리"
  재료 선택 → 조리 → 완성 연출 풀로 재생 (빛 터짐 + 팡파르, 튜토리얼이어도 생략 없음)
  미아 컷씬: "세상에... 이게 진짜 먹을 수 있는 거예요?!"

[4:00~5:00] — "누군가 먹는다"
  식당으로 이동 → 그롬 자동 등장
  슬라임 젤리 서빙 → 먹는 연출 → "쫄깃하고 달콤해?! 몬스터 요리라니!"
  골드 획득 + Day 1 클리어 화면

[5:00~] — "이제 세계가 열린다"
  미아: "이제 이 식당을 제대로 운영해봐요"
  이 시점부터 인벤토리, 스탯, 업그레이드 UI가 하나씩 등장
```

---

**온보딩 4원칙**

| 원칙 | 내용 |
|---|---|
| 설명 대신 행동 | 첫 5분 텍스트 박스 최소화. 시스템은 행동으로 유도 |
| 감정 먼저 | 완성 연출은 튜토리얼이어도 풀버전 그대로. 타협 없음 |
| 실패 없는 구간 | 첫 던전 슬라임만 등장, 플레이어 HP 사실상 무한 (기획적 안전망) |
| 시스템 지연 공개 | 인벤토리·스탯·업그레이드는 5분 이후부터. 첫 화면을 깨끗하게 유지 |

> **방향성과의 균형**: 튜토리얼이 짧다는 것은 게임이 얕다는 뜻이 아니다.
> 데이브 더 다이버의 첫 잠수도 설명 없이 시작된다 — 그게 그 게임의 깊이를 해치지 않는 것처럼.

## 4. 주요 시스템 상세

### 4.1 던전 탐험 시스템

**기본 구조**
- 탑뷰(Top-down) 2D 액션 — 위에서 내려다보는 시점, 8방향 자유 이동
- 던전은 여러 방(Room)으로 구성, 방 진입 시 문이 잠기고 몬스터 처치 시 개방
- 각 방: 몬스터 배치 + 함정 + 환경 오브젝트 (기둥, 용암, 독 웅덩이 등)
- 마지막 방: 보스 몬스터 (고유 패턴 + 대량 식재료 드롭)
- 참고 느낌: 하데스(Hades), 엔터더건전(Enter the Gungeon) 스타일 탑뷰 액션

**조작 방식 (모바일/PC 공용)**
| 입력 | 모바일 | PC |
|---|---|---|
| 8방향 이동 | 가상 조이스틱 | WASD 또는 방향키 |
| 기본 공격 | 공격 버튼 (방향 자동 조준) | Z 또는 마우스 좌클릭 (커서 방향) |
| 스킬 1 (쿨타임) | 스킬1 버튼 | X |
| 스킬 2 (쿨타임) | 스킬2 버튼 | C |
| 궁극기 (게이지) | 궁극기 버튼 | V |
| 구르기/회피 | 2번 탭 or 버튼 | Shift / 마우스 우클릭 |
| 상호작용 | 버튼 | F |

**속성 시스템**

캐릭터의 **기본 공격과 초기 스킬은 물리 속성으로 고정**된다. **마지막 공격(막타)에 사용된 속성**이 몬스터에서 드롭되는 재료의 상태를 결정한다 — 이것이 전투와 요리를 연결하는 핵심 메커니즘.

**속성 설계 원칙**
- 기본 공격·초기 스킬 = **물리(Physical)** 고정 → 안정적인 기본 재료 수급 보장
- 속성 스킬은 플레이어가 **자유롭게 선택** — 원하는 재료를 위해 선택하는 것, 데미지를 위해 강제되어선 안 됨
- 물리 막타로도 충분히 진행 가능한 레시피 라인이 항상 존재
- 속성 스킬은 "더 다양한 재료"를 위한 선택지, "더 강한 공격"을 위한 필수 요건이 아님

속성 종류: **물리 / 불꽃 / 전기 / 물 / 땅 / 바람 / 냉기 / 마법 / 독** (총 9종)

**속성별 재료 상태 — 막타 속성 드롭 테이블**

| 막타 속성 | 재료 상태 | 설명 | 요리 활용 |
|---|---|---|---|
| ⚔️ 물리 | **기본 생 재료** | 안정적인 기본 부위 드롭, 가죽·고기 포함 | 대부분의 기본 레시피 커버, 범용적 활용 |
| 🔥 불꽃 | **구워진 재료** | 가열로 가죽/껍질 소실, 육질은 이미 익힘 | 훈제 요리, 구이, 바베큐 직행 |
| ⚡ 전기 | **감전 익힘 재료** | 순간 열처리로 육즙 보존, 껍질 약간 그을음 | 촉촉한 찜 요리, 전기구이 |
| 💧 물 | **신선한 생 재료+** | 씻겨진 상태, 가죽/뼈/피 전부 온전히 드롭 | 회, 육회, 탕, 스튜 등 폭넓게 활용 |
| 🪨 땅 | **생 재료 + 뼈 보존** | 충격 처치, 뼈 추가 드롭, 부위 온전 | 사골 육수, 껍질 요리 |
| 🌀 바람 | **건조된 재료** | 수분 제거, 말린 상태로 드롭 | 건어물, 육포, 분말 향신료 |
| ❄️ 냉기 | **냉동 재료** | 급속 냉동, 신선도 최고 등급 | 카르파초 등 신선도 요구 고급 요리 |
| ✨ 마법 | **마력 깃든 재료** | 마나 함유, 발광 상태 | 버프 요리, 마법 포션 재료 |
| ☠️ 독 | **오염/부패 재료** | 독소 함유, 일반 요리 불가 | 독 요리 (특수 레시피), 해독제 재료 |

> **예시 — 박쥐 몬스터 처치 결과**
> - ⚔️물리 막타 → `박쥐 생고기` + `박쥐 가죽` (기본 안정 드롭, 대부분 레시피 가능)
> - 🔥불꽃 / ⚡전기 막타 → `구운 박쥐 고기` (가죽 없음, 구이·훈제 레시피 전용)
> - 💧물 / 🪨땅 막타 → `박쥐 생고기(+)` + `박쥐 뼈` (육수탕·스튜 최적)
> - ❄️냉기 막타 → `냉동 박쥐 고기` (신선도 MAX, 고급 레시피 전용)
> - ✨마법 막타 → `마력 깃든 박쥐 고기` (버프 요리 전용)
> - ☠️독 막타 → `오염된 박쥐 고기` (독 레시피 전용)

**전략적 선택 유도 — 강요 없는 다양성**
- 물리 막타만으로 기본 레시피 전 라인 커버 가능 → 누구나 막히지 않고 진행
- 속성 스킬은 특정 레시피를 위한 선택지 → "냉동 박쥐 카르파초 만들고 싶다" → 냉기 스킬 준비
- 속성 약점 공략 시 데미지 보너스가 아닌 **드롭량 보너스**만 적용 → 전투 속도가 아닌 재료 효율로 보상

**속성별 전투 피드백 (Juice 연계)**
- 막타 속성이 재료 상태를 바꾸는 만큼, 시각/청각 피드백도 속성별로 완전히 달라야 함
- 냉기 막타: 얼음 결정 파티클 + 서리음 → 재료가 냉동 상태로 드롭되는 시각적 연결
- 불꽃 막타: 화염 파티클 + 지글거리는 음 → 재료가 구워진 채로 드롭
- 이 연결이 명확할수록 "전투가 곧 요리 준비"라는 핵심 판타지가 강해짐

**식재료 수급 메커니즘 (전체 정리)**

| 처치 방식 | 드롭 내용 |
|---|---|
| 기본 공격 막타 (물리) | 기본 생 재료 고정 드롭 1~2종 (안정적) |
| 속성 스킬 막타 | 해당 속성 재료 상태 드롭 |
| 약점 속성 막타 | 속성 재료 + 드롭량 +50%, 추가 희귀 부위 확률 |
| 궁극기 막타 | 속성 재료 + 전 부위 풀 드롭 (최고 수율) |
| 포획 (HP 20% 이하) | `살아있는 재료` — 특수 레시피 전용 최고급 |

**던전 모드 종류**
| 모드 | 설명 | 보상 |
|---|---|---|
| 스토리 던전 | 메인 진행, 층수 개방 | 스토리, 레시피, 재료 |
| 일일 던전 | 매일 초기화, 목표 다양 | 골드, 희귀 재료, 에테르 |
| 보스 레이드 | 최대 4인 협동, 주간 | 전설 재료, 장비 |
| 자동 탐험 (소탕) | 클리어 완료 층 자동 파밍 | 일반 재료 (시간 기반) |
| 무한 던전 | 엔드게임 콘텐츠, 랭킹 | 특수 화폐 |

### 4.2 요리 시스템

**레시피 구조**
```
[식재료 A] + [식재료 B] + [향신료/허브] + [조리기구] → [완성 요리]
```
- 레시피 발견: 던전 탐험 중 레시피 책 획득 / 식재료 조합 실험 / NPC 이벤트 / 업그레이드 해금
- 동일 재료도 **조리법**이 다르면 완전히 다른 요리 → 같은 박쥐 고기로 구이·탕·육회·훈제 가능

---

**조리법 & 조리기구 해금 시스템**

레스토랑 업그레이드 = 새 조리기구 설치 = 새 조리법 해금. 초반엔 단순한 요리만 가능하고, 업그레이드할수록 요리의 폭이 확장된다.

| 조리기구 | 해금 시점 | 해금되는 조리법 | 예시 요리 |
|---|---|---|---|
| 🔪 기본 도마 | 시작 | 날것, 손질 | 육회, 생야채 무침 |
| 🔥 화덕 | 식당 Lv.2 | 굽기, 훈제 | 구이, 바베큐, 훈제육 |
| 🫕 냄비/화로 | 식당 Lv.3 | 끓이기, 조림 | 탕, 스튜, 육수, 조림 |
| 🧊 냉동고 | 식당 Lv.4 | 냉동 숙성, 냉장 보관 | 카르파초, 아이스크림, 냉면 |
| 🫙 발효 항아리 | 식당 Lv.5 | 발효, 절임 | 김치류, 된장류, 삭힌 요리 |
| ⚗️ 마법 증류기 | 식당 Lv.6 | 증류, 정제 | 마법 포션, 에센스 요리 |
| 🍳 철판·튀김솥 | 식당 Lv.7 | 볶음, 튀김 | 볶음밥, 튀김, 전 |
| 🎂 제과 오븐 | 식당 Lv.8 | 굽기(베이킹) | 몬스터 파이, 케이크 |
| 🌀 마나 스모커 | 식당 Lv.9 | 마법 훈연 | 마력 깃든 훈제 요리 |
| 🏺 고압 증기솥 | 식당 Lv.10 | 고압 찜, 압력 조리 | 극한 부드러운 찜 요리 |

> **설계 의도**: 새 조리기구 설치 때마다 "이 재료로 이런 요리도 되네!" 발견의 기쁨 제공.
> 데이브 더 다이버의 새 지역 개방과 같은 경이로움을 주방에서도 느끼도록.

---

**요리 마스터리 — 요리 소모 강화 시스템 (데이브 더 다이버 참고)**

같은 요리를 반복적으로 소모(제출)하면 해당 요리의 숙련도(마스터리)가 쌓인다.
숙련도가 올라갈수록 그 요리가 강화되어 더 비싸게 팔리고, 추가 효과가 붙는다.

```
[요리 소모] → 마스터리 경험치 → 마스터리 레벨업 → 요리 강화
```

| 마스터리 레벨 | 조건 | 강화 효과 |
|---|---|---|
| Lv.1 (초급) | 기본 | 기본 판매가 |
| Lv.2 (숙련) | 동일 요리 20회 소모 | 판매가 +20%, 조리 시간 -10% |
| Lv.3 (전문) | 50회 | 판매가 +45%, 특별 손님 유치 확률↑ |
| Lv.4 (명인) | 100회 | 판매가 +80%, 전용 손님 대사 추가, 레어 재료 부재료 허용 |
| Lv.5 (전설) | 200회 | 판매가 +150%, 요리에 고유 이름 부여, 메뉴판 빛남 이펙트 |

- "소모"의 의미: 판매 외에 NPC 증정, 던전 출격 전 섭취, 길드 기부 등 모두 마스터리 카운트 포함
- 마스터리 높은 요리일수록 특정 VIP 손님이 찾아옴 → 스토리 이벤트 트리거

---

**요리 등급**

재료의 상태(막타 속성)가 요리 등급에 직접 영향을 줌.

| 등급 | 조건 | 판매가 보정 | 부가 효과 |
|---|---|---|---|
| 보통 (Normal) | 재료 충족, 상태 불일치 | 기준 | - |
| 맛있어! (Good) | 레시피 요구 재료 상태 일치 | +40% | 손님 만족도↑ |
| 완벽한 (Perfect) | 요구 상태 + 약점 속성 막타 재료 | +90% | 명성↑↑, 재방문율↑ |
| 전설의 맛 (Legendary) | 포획 재료 or 궁극기 막타 재료 | +200% | VIP 유치, 마스터리 2배 획득 |

**요리 미니게임 (선택적)**
- 자동 요리 vs 직접 요리 미니게임 선택 가능
- 미니게임 성공 시 등급 +1 확률 OR 마스터리 경험치 +50% 보너스

**캐릭터 버프 요리**
- 출격 전 특정 요리 섭취 → 일시 능력치 상승
- 마스터리가 높을수록 버프 지속시간·효과 상승
- 예: Lv.3 박쥐 육수탕 섭취 → 방어력 +20%, 물 속성 재료 드롭률 +15% (30분)

### 4.3 식당 운영 시스템

**식당 운영 구조 — 직접 운영 → 위임으로 성장**

> 동물의 숲, 데이브 더 다이버처럼 초반엔 직접 운영하고, 직원 고용으로 점차 위임하는 구조.
> 식당이 커질수록 플레이어가 해방되어 던전에 더 집중할 수 있게 됨.

| 단계 | 운영 방식 | 플레이어 역할 |
|---|---|---|
| 초반 (직원 없음) | 플레이어 직접 주문·서빙·결제 | 모든 것을 직접 처리, 바쁘고 정신없지만 몰입감 최고 |
| 중반 (직원 1~2명) | 단순 서빙·결제는 직원 위임 | VIP 응대, 특수 주문, 요리 품질 관리에 집중 |
| 후반 (직원 풀 고용) | 직원이 대부분 운영 자동화 | 메뉴 구성·업그레이드 결정만. 영업 중 던전 탐험 가능 |

**식당 구조**
- 좌석 수: 초기 4석 → 최대 30석 확장
- 메뉴판: 동시 등록 요리 수 제한 (초기 5종 → 업그레이드로 증가)
- 종업원 (NPC): 고용 후 서빙·결제 담당, 레벨업으로 서비스 속도·친절도 상승

**손님 시스템**
- 일반 손님: 매일 자동 방문, 주문 → 결제 → 만족도 부여
- 모험가 손님: 특정 요리 주문 → 보상 퀘스트 (재료 힌트, 의뢰 등)
- VIP 손님: 명성 조건 충족 시 등장, 고가 주문 + 스토리 해금
- 비밀 손님 (미식가): 완벽 요리만 인정 → 리뷰 → 명성 대폭 상승

**영업 지표**
- 매출 (골드): 식당 운영 주 수입
- 명성 (Fame): 식당 레벨 = 더 어려운 손님 요구 + 더 좋은 보상
- 만족도: 요리 품질 + 서비스 속도 → 재방문율

**식당 업그레이드**
- 주방: 동시 요리 슬롯, 요리 속도, 보관 창고 용량
- 홀: 좌석 수, 인테리어 (테마별 명성 보너스)
- 간판: 특정 손님 유치 (모험가 전문, 귀족 전문 등)

### 4.4 캐릭터 & 파티 시스템

**캐릭터 수집**
- 다양한 모험가/요리사 캐릭터
- 역할: 전사(탱커) / 마법사(마법 딜러) / 도적(물리 딜러) / 사제(힐러/버퍼) / 요리사(식당 특화)
- 캐릭터 간 차별점은 스킬 구성에서 가져감 — 별도 드롭 보너스 없음
- 속성 차별화는 속성 시스템이 담당 (막타 속성 → 재료 상태 결정)
- **Phase 1**: 스토리 지급 또는 퀘스트 해금 전용 — 가챠 없음
- **Phase 2**: 가챠 캐릭터 추가 (에테르 소모)

**파티 구성**
- 던전 입장 시 3인 파티 고정 (4인은 협동 레이드 전용)
- 파티 3명이 액티브 스킬 2개씩 → 최대 6가지 속성 커버 가능
- 출격 전 "오늘 어떤 재료를 파밍할지"에 따라 파티 조합이 달라지는 구조

**성장 시스템**
- 레벨업: 전투 경험치 → 기본 능력치 상승 + **스킬 포인트 획득**
- 장비: 던전 드롭 / 골드 제작 → 무기, 방어구, 액세서리
- 스킬 트리: 스킬 포인트로 강화 (아래 상세)
- 요리 버프 적용: 출격 전 식사 선택

**스킬 구성 (확정)**

| 슬롯 | 내용 |
|---|---|
| 패시브 | 1개 고정 — 항상 적용되는 캐릭터 고유 특성 |
| 액티브 | 3개 보유, 그 중 2개 장착 — 기본 공격은 별도 (물리 고정) |

**스킬 트리 구조 (구현 시 상세화 예정)**

> 모든 캐릭터의 스킬 트리 형태는 동일. 각 액티브 스킬마다 아래 구조를 가짐.
> 설계 기준: 스킬당 7~10 노드 × 3스킬 = 총 21~30 노드 (미드코어 적정 규모).
> 포인트 총량 < 전체 노드 수 → 완성 불가 설계, 빌드 다양성 보장.

```
[액티브 스킬]
  │
  ├ 1단계 — 수치 강화 (스킬 포인트)
  │   예: 쿨타임 감소 / 데미지 증가 / 관통 횟수 추가
  │
  ├ 2단계 — 패턴 강화 (스킬 포인트)
  │   예: 범위 확장 / 상태이상 지속시간 증가 / 잔류 이펙트 생성
  │
  ├ 3단계 — 연계 강화 (스킬 포인트)
  │   예: 조건부 추가 타격 / 콤보 확장 / 파티원 연계 효과
  │
  └ 최종 분기 — 질적 변형 (특수 재화, 1개만 선택)
      예A: 속성 추가 (냉기 → 냉기+독, 빙결 해제 시 독 폭발)
      예B: 형태 변형 (관통 창 → 광역 폭발, 특성 교체)
      예C: 재료 드롭 연동 (명중 적 속성 변화 → 드롭 재료 상태 변경)
```

> ⚠️ 구현 시 결정할 것: 단계별 노드 개수, 포인트 비용 곡선,
> 특수 재화 명칭 및 획득처, 스킬 리셋 가능 여부
>
> 참고: 업계 데이터상 잘 설계된 스킬 트리는 노드의 76%가 의미있게 인식됨.
> 수치만 올리는 노드는 최소화, 질적 변화 노드 비중을 높일 것. (DESIGN_REFERENCES 섹션 3)

## 5. 스토리 & 세계관

### 5.1 배경
판타지 세계 '아스테리아'. 던전이 도처에 존재하며 모험가들이 득실대는 세계. 플레이어는 전직 모험가 출신으로, 던전 탐험 중 발견한 '몬스터도 먹으면 맛있다'는 사실에 눈뜨고 식당을 차린다.

### 5.2 주인공
- **이름**: 커스터마이징 가능
- **설정**: 전직 S급 모험가, 은퇴 후 식당 오픈. 직접 전투도 가능한 전투요리사
- **동기**: "세상에서 가장 맛있는 몬스터 요리를 완성하겠다"

### 5.3 주요 NPC
- **미아**: 견습 요리사, 식당 매니저 역할. 레시피 힌트 제공

- **아리사**: 마법사 라이벌, 이벤트 스테이지 트리거
- **마왕**: 최종 던전 보스이자 VIP 손님... (반전 요소)

### 5.5 주요 빌런

## 6. 연출 철학 (Presentation Direction)

> 데이브 더 다이버의 연출 방식을 핵심 레퍼런스로 삼는다.
> **"사소한 순간도 이벤트가 된다" — 모든 성취에 연출로 반응한다.**

### 6.1 컷씬 원칙

**데이브 더 다이버가 증명한 것**: 컷씬은 거대한 스토리 분기점에만 쓰는 것이 아니다.
요리 완성, 새 레시피 발견, 첫 손님 방문 같은 **일상적이고 사소한 순간**에 짧은 컷씬을 배치할 때 플레이어는 게임 세계가 살아있다고 느낀다.

| 트리거 | 연출 종류 | 길이 |
|---|---|---|
| 새 요리 완성 (처음) | 풀 컷씬 — 요리 드라마틱 클로즈업 + 캐릭터 리액션 | 5~8초 |
| 요리 등급 상승 | 짧은 연출 — 빛 터짐 + 등급 뱃지 등장 | 2~3초 |
| 몬스터 첫 처치 | 몬스터 도감 등록 컷 + "새 재료 발견!" 팝업 | 3~5초 |
| 던전 보스 처치 | 중간 컷씬 — 보스 쓰러지는 연출 + 드롭 아이템 연출 | 8~15초 |
| 첫 VIP 손님 방문 | 입장 연출 — 문 열리는 사운드 + 드라마틱 포즈 | 5초 |
| 레시피 발견 | 레시피 책 펼쳐지는 연출 + 요리 일러스트 공개 | 4~6초 |
| 스토리 이벤트 | NPC 대화 + 풀 씬 | 30~90초 |
| 레벨업 / 식당 업그레이드 | 빛 폭발 + Before/After 전환 | 3~5초 |

### 6.2 연출 스타일 — 과장된 유머와 감동의 균형

데이브 더 다이버의 컷씬은 **"이 정도까지 할 줄 몰랐다"**는 반응을 유발하는 과잉 연출이 특징.
우리 게임도 동일한 방향을 따른다:

- **요리 완성 연출**: 단순 이펙트가 아닌, 요리에서 빛이 쏟아지고 캐릭터가 눈물을 닦는 과장된 반응
- **배경 공감 리액션**: 식당 손님들이 음식 보고 일제히 침 삼키는 장면, 몬스터가 도망가는 코믹 컷
- **적절한 진지함**: 스토리 분기점에서는 진지한 분위기로 전환 — 유머와 감동이 공존
- **캐릭터 표정 연기**: 픽셀아트 스프라이트도 다양한 표정 프레임으로 감정 전달

### 6.3 시각적 연출 레이어

```
[최상위] 풀스크린 컷씬 / 대화 씬
    ↕
[중간] 게임플레이 위 오버레이 이펙트
       (요리 완성 파티클, 등급 뱃지, 골드 획득 팝업)
    ↕
[게임플레이] 인게임 이펙트
             (속성 공격 이펙트, 몬스터 처치 연출, 식당 손님 리액션)
    ↕
[배경] 배경 애니메이션
       (식당 불빛, 던전 떨어지는 먼지, 창 밖 날씨 변화)
```

### 6.4 사운드 연출 연계

- 모든 컷씬에 전용 효과음 + 짧은 스팅(sting) 음악
- 요리 완성: 화려한 팡파르 → 손님 탄성 SFX
- 보스 등장: 위협적인 브라스 + 화면 흔들림
- 식당 영업 BGM: 조용한 저녁 재즈 → 손님 많을수록 템포 상승

### 6.5 미니게임 연출 — 스토리에 자연스럽게 삽입

데이브 더 다이버처럼 미니게임은 "이 타이밍에 이런 게임이?"라는 반응이 나올 만큼 **예상치 못한 순간** 등장:

| 미니게임 | 등장 타이밍 | 연출 방식 |
|---|---|---|
| 요리 타이밍 게임 | 레전드 요리 첫 도전 시 | 요리사가 긴장하는 컷 → 리듬 게임 전환 |
| 낚시 / 포획 게임 | 희귀 몬스터 포획 시도 시 | 화면이 확대되며 긴장감 연출 |
| 식재료 신선도 경매 | 특정 NPC 이벤트 | 경매장 분위기 BGM + 입찰 경쟁 |
| 보스전 특수 페이즈 | 보스 HP 50% 이하 | 보스가 폼 변환 컷씬 후 미니게임 전환 |
| 요리 대회 | 시즌 이벤트 | 심사위원 등장 컷씬 + 채점 연출 |

## 7. 아트 방향성

- **스타일**: 따뜻한 카툰 판타지 (던전밥 원작 느낌) + 데이브 더 다이버의 생동감 있는 픽셀 표현력
- **색감**:
  - 던전 (낮/오전): 황토·돌·초록 자연색, 깊어질수록 짙어지는 어둠
  - 던전 (심층): 청보라 + 마법 발광, 발광 몬스터 실루엣
  - 식당 (오후/저녁): 따뜻한 황금빛 조명, 목조 인테리어
- **캐릭터**: 2D 픽셀아트 스프라이트 + 스켈레탈 애니메이션 (com.unity.2d.animation)
  - 표정 변화용 다중 페이스 프레임 (기본/기쁨/놀람/슬픔/화남 최소 5종)
- **타일**: 64×64px 기준, Aseprite로 제작 (com.unity.2d.aseprite)
- **컷씬**: 픽셀아트 캐릭터 + 별도 고해상도 배경 일러스트 레이어 혼합
- **이펙트**: URP 2D 파티클 + 발광 쉐이더 + Shader Graph 기반 속성 이펙트

### 8.1 Phase 1 — 솔로 스토리 경험 (Day 0 ~ 30)

**설계 목표**: 플레이어가 최소 한 달은 스토리에 몰입하여 즐길 수 있는 **완결된 콘솔 게임 수준의 경험** 제공.
데이브 더 다이버처럼 — 경쟁 없이, BM 압박 없이, 순수하게 세계에 빠져들 수 있어야 한다.

**핵심 원칙**
- 경쟁 요소 완전 없음 — 랭킹, PVP, 길드 없음
- 타 유저가 내 게임에 영향을 미치지 않음
- 이 기간의 콘텐츠 볼륨은 **한 번 확정되면 절대 삭제·변경하지 않음** (업데이트로 추가만 가능)

**콘텐츠 설계 — 30일치 분량**

| 구간 | 일수 | 주요 해금 콘텐츠 |
|---|---|---|
| 초반 | Day 1~7 | 기본 던전 1~2구역, 식당 기초, 파티 캐릭터 2명 지급 |
| 중반 | Day 8~15 | 던전 3~4구역, 레시피 연구, 직원 고용, NPC 서브 스토리 |
| 후반 | Day 16~24 | 던전 5~6구역, 보스 레이드 (솔로), VIP 손님, 전설 레시피 |
| 클라이맥스 | Day 25~30 | 최종 던전, 메인 스토리 클라이맥스, 엔딩 컷씬 |

**캐릭터 수급 — Phase 1 전용**

| 방식 | 내용 |
|---|---|
| 스토리 지급 | 스토리 진행 중 자동 합류 — 총 4~6명. 각각 스토리 컷씬 포함 |
| 명함 캐릭터 | 게임 시작 시 기본 제공되는 주인공 + 베이스 파티. Phase 1 완주에 충분한 성능 |

| **가챠 없음** | Phase 1 기간 중 캐릭터 가챠 미노출 |

> **원칙**: Phase 1을 무과금으로 완주했을 때 스토리가 완결되고 만족감이 있어야 한다.
> 과금은 선택이지 필수가 아님을 플레이어가 느껴야 한다.

**Phase 1 BM — 최소화**

> 핵심 원칙: 플레이를 **강제로 끊는** 장치 없음. 더 편하게 즐기고 싶은 욕구를 자극하는 방식으로만.

| 상품 | 내용 | 원칙 |
|---|---|---|
| 코스튬/스킨 | 캐릭터·식당 외관 변경 | 성능 무관 |

### 8.2 Phase 2 — 경쟁 서버 (Day 30+)

**설계 목표**: 스토리를 완주한 플레이어들이 동일한 세계관 안에서 경쟁하는 **라이브 서비스 MMORPG**로 전환.
Phase 1 기반을 유지하되, 서버 경쟁·길드·P2W 레이어가 위에 올라간다.

**전환 구조**
- Day 30 메인 스토리 클리어 → "세계가 열린다" 연출 → 경쟁 서버 합류 프롬프트
- Phase 1 자산(캐릭터, 식당, 장비)은 그대로 Phase 2로 이어짐
- 단, Phase 2 경쟁에서 Phase 1 자산만으로는 중상위권 유지 어려움 → 성장 압박 설계

#### 8.2.1 시즌 시스템 (라스트워 구조 참고)

- **시즌 주기**: 4주 1시즌
- **시즌 랭킹**: 개인 전투력 랭킹 + 식당 명성 랭킹 + 길드 랭킹 3트랙
- **리그 구조**:
  ```
  마스터 리그  (상위 5% 길드)  — 전설 레이드 던전 입장권 독식
  다이아 리그  (상위 15%)     — 고급 레이드 접근
  골드 리그    (상위 30%)     — 일반 경쟁 참여
  실버 리그    (나머지)        — 기초 경쟁
  ```
- 시즌 종료 시 리그 승강격 + 시즌 한정 보상 지급
- **시즌 리셋**: 전투력 일부 리셋 (장비 제외), 새 시즌 과금 유도

#### 8.2.2 길드 시스템 (라스트워 + 화이트아웃 구조 참고)

**길드 구성**
- 최대 50명, 길드 마스터 + 부마스터 + 일반 구조
- 길드 자체 "공동 식당" 운영 → 길드 레벨 = 공동 식당 등급

**기여도 & 민폐 방지 (화이트아웃 서바이벌 구조)**

| 기여 활동 | 기여 포인트 |
|---|---|
| 일일 던전 클리어 | 10pt |
| 길드 레이드 참여 | 50pt |
| 공동 식당 재료 기부 | 재료가치 × 1pt |
| 길드 전쟁 참여 | 30pt |
| 주간 퀘스트 달성 | 20pt |

- 주간 기여 포인트 최소치 미달 → 길드 경고 누적 → 강제 탈퇴
- 길드 가입 조건: 최소 전투력 기준 + 기여 의지 표명 (활성 유저 필터)
- 길드 랭킹 = 전체 기여 포인트 합산 → 길드 레이드 던전 우선권 결정

**길드 vs 길드 경쟁**
- 주간 길드전: 지역 구역 점령 → 해당 구역 던전 입장권 수급량 +X%
- 시즌 결승: 상위 16개 길드 토너먼트 → 챔피언 길드는 다음 시즌 전설 던전 독점 접근

#### 8.2.3 레이드 던전 독식 구조 (리니지M 구조 참고)

**던전 점령 시스템**
```
전설 레이드 던전 (층당 1개)
    ↓
상위 길드가 "던전 지배권" 보유
    ↓
지배 길드: 입장 자유 + 드롭 독식
비지배 유저: 입장 시 지배 길드의 허가 또는 전투 필요
    ↓
다른 길드가 도전 → 점령전 발생 (주 1회)
```

**혈맹형 세력 구조 (리니지 구조)**

| 세력 | 설명 |
|---|---|
| 지배 길드 (왕 길드) | 최상위 레이드 독점, 서버 지배, 타 길드에 세금(재료) 요구 가능 |
| 반왕 길드 | 지배 길드에 맞서는 세력, 점령전 도전권 보유 |
| 동맹 길드 | 지배/반왕 길드에 우호적, 입장권 일부 배분 |
| 중립 길드 | 경쟁 미참여, 기본 던전만 접근 |

**재료 세금 시스템**
- 지배 길드가 특정 던전 보스 처치 시 드롭 재료의 10% 자동 세금 획득
- 이 재료는 지배 길드의 공동 식당으로 귀속 → 식당 명성 랭킹 1위 유지 수단

#### 8.2.4 P2W 설계 — Phase 2 BM

> Phase 2는 의도적인 P2W 구조. 단, 과금의 효율 구조를 투명하게 설계해 유저 신뢰 유지.

| 상품 | 내용 | Phase 2 영향 |
|---|---|---|
| 가챠 캐릭터 | 에테르 소모, 전투 특화 고성능 캐릭터 | 전투력 직접 상승 |
| 전투력 강화 패스 | 월정액, 일일 재화 지급 | 중과금 유저 유지 도구 |
| 시즌 배틀패스 | 시즌 한정 장비/레시피/스킨 | 랭킹 경쟁 우위 |
| 길드 지원 패키지 | 기여 포인트 부스터, 재료 묶음 | 길드 기여도 구매 |
| 전설 레이드 입장권 | 지배 길드 외 입장권 직접 구매 | 독점 구조 우회 가능 (상징적) |
| VIP 등급 | 월정액 누적으로 특권 부여 | 전투력 버프, 전용 컨텐츠 |

**P2W 설계 원칙**
- 과금 효율 투명 공개 (% 표기)
- 무과금 유저도 충분한 기여로 길드 잔류 가능 (단, 상위권은 힘듦)
- 시즌 리셋으로 진입 장벽 주기적 초기화 → 신규 과금 유저 유입 지속
