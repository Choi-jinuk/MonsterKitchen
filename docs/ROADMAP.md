## Phase 1 — 핵심 루프 프로토타입
> 목표: "던전 탐험 → 재료 획득 → 요리 → 판매" 1 사이클 플레이 가능

**데이터 파이프라인 (우선 구축)**
- [ ] `GameEnums.cs` — AttributeType, IngredientState, RarityType Enum 정의
- [ ] SO 클래스 작성 (MonsterData, IngredientData, RecipeData, DropTableData, CharacterData)
- [ ] `CsvParser.cs` — `;` 주석, `_` 무시 컬럼, `#TYPE` 힌트, 배열(`|`) 지원
- [ ] `CsvReadWriter.cs` — 주석/무시컬럼 보존하며 CSV 읽기/쓰기
- [ ] `ScriptableObjectSync.cs` — ID 기준 SO 생성/갱신/삭제
- [ ] `ExcelSync.cs` — EPPlus(또는 NPOI)로 Excel 시트 양방향 동기화
- [ ] `SyncCoordinator.cs` — CSV → SO → Excel 순차 동기화 오케스트레이터
- [ ] `DataManagerWindow.cs` — 통합 Editor 창 (Browser 탭 + Statistics 탭)
  - [ ] 테이블 뷰 (검색, 필터, 정렬)
  - [ ] 행 추가/삭제 (즉시 동기화)
  - [ ] 하단 상세 편집 패널
  - [ ] Statistics 탭 (속성 분포, HP 히스토그램, 무결성 리포트)
- [ ] `DataRegistry.cs` — 런타임 ID→SO 조회 레지스트리
- [ ] 초기 기획 데이터 Excel 작성 → Data Manager로 임포트 검증

**던전 시스템**
- [ ] 탑뷰 던전 씬 구성 (타일맵 + 방 구조)
- [ ] 플레이어 8방향 이동/공격 구현 (New Input System, 가상 조이스틱 포함)
- [ ] 몬스터 기본 AI (순찰, 공격, 처치)
- [ ] 식재료 드롭 시스템 (ScriptableObject 기반 드롭 테이블)
- [ ] 던전 층 구성 (3층 + 보스)

**요리 & 식당 시스템**
- [ ] 식재료 인벤토리 UI
- [ ] 레시피 ScriptableObject 데이터 구조
- [ ] 기본 요리 제작 (재료 조합 → 완성 요리)
- [ ] 식당 씬 (탑뷰 or 사이드뷰) 기본 구성
- [ ] 손님 NPC 기본 로직 (등장 → 주문 → 결제)
- [ ] 골드 수입/지출 기초

**씬 전환**
- [ ] 던전 씬 ↔ 식당 씬 전환 시스템
- [ ] 로딩 화면

## Phase 2 — 게임플레이 확장
> 목표: 핵심 시스템 완성, 플레이어가 루프를 체감 가능

**던전 확장**
- [ ] 속성 시스템 (불꽃/수냉/바람/땅/마법/독)
- [ ] 몬스터 5종 이상 구현 (고유 AI + 드롭 테이블)
- [ ] 스킬 시스템 (쿨타임, 속성 스킬)
- [ ] 궁극기 게이지 시스템
- [ ] 자동 탐험 (소탕) 기능 — 클리어한 던전 자동 파밍
- [ ] 일일 던전 (Daily Dungeon) 시스템

**요리 & 식당 확장**
- [ ] 요리 등급 시스템 (Normal / Good / Perfect / Legendary)
- [ ] 손님 타입 다양화 (일반/모험가/VIP)
- [ ] 명성(Fame) 시스템 및 식당 레벨
- [ ] 식당 업그레이드 (좌석, 주방, 인테리어)
- [ ] 메뉴판 시스템

**캐릭터 성장**
- [ ] 레벨업 및 기본 스탯 성장
- [ ] 장비 시스템 (던전 드롭/제작)
- [ ] 식사 버프 시스템 (출격 전 요리 섭취)

**스토리 & UI**
- [ ] 메인 메뉴 씬 (Boot / MainMenu / Game 씬 분리)
- [ ] 기본 HUD (체력바, 골드, 명성, 인벤토리)
- [ ] 스토리 다이얼로그 기초 (NPC 대화)
- [ ] 저장/불러오기 시스템

**연출 시스템 (데이브 더 다이버 스타일)**

- [ ] 몬스터 첫 처치 → 도감 등록 컷 연출

## MVP 목표 — "하나의 사이클이 끊김없이 돌아간다"

> 수치 밸런스는 MVP 이후. 지금은 구조가 작동하는 것이 목표.
> 모든 수치는 CSV로 관리 → Data Manager 툴에서 조율.

### MVP 구현 순서

**Step 1 — 데이터 파이프라인** (구조의 기반)
- [ ] `GameEnums.cs` — AttributeType, IngredientState, RarityType, CharacterRole
- [ ] SO 클래스 5종 — MonsterData, IngredientData, RecipeData, FoodData, DropTableData
- [ ] `CsvParser.cs` + `CsvReadWriter.cs`
- [ ] `ScriptableObjectSync.cs`
- [ ] `DataManagerWindow.cs` (Browser 탭 우선, Statistics 탭은 이후)
- [ ] `DataRegistry.cs`
- [ ] 초기 CSV 데이터 입력 (에버그린 숲 몬스터 5종 + 재료 + 레시피)

**Step 2 — 던전 (핵심 루프 전반부)**
- [ ] 플레이어 이동/공격 (New Input System, 8방향)
- [ ] 슬라임 몬스터 1종 구현 (MonsterAI FSM)
- [ ] 막타 속성 감지 → DropResolver → 재료 드롭
- [ ] 인벤토리 (재료 수집)
- [ ] 에버그린 숲 방 1개 (타일맵)

**Step 3 — 요리 (핵심 루프 중간)**
- [ ] 주방 씬 이동
- [ ] 레시피 매칭 (재료 조합 → RecipeData 조회)
- [ ] 슬라임 젤리 완성 연출 (기본 파티클 + 사운드)
- [ ] FoodData 생성 → 인벤토리에 추가

**Step 4 — 식당 (핵심 루프 후반부)**
- [ ] 손님 1명 등장 (CustomerAI FSM)
- [ ] 메뉴 세팅 → 서빙 → 골드 획득
- [ ] 영업 마감 → 다음 날 전환

**Step 5 — 사이클 연결**
- [ ] 던전 → 주방 → 식당 → 다음 날 씬 전환
- [ ] Day 카운터
- [ ] 기본 HUD (골드, 인벤토리)
